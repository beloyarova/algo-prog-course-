# algo-prog-course-

## ПР1. Ответы на контрольные вопросы

1. Чем компилируемый язык (C#) отличается от интерпретируемого (Python) с точки зрения того, когда обнаруживаются ошибки?

В C# ошибки находятся ещё до запуска программы — на этапе компиляции. Если в коде есть ошибка, программа вообще не соберётся.  
В Python ошибки находятся только во время работы программы, потому что код выполняется построчно.

2. Что делает команда `dotnet run` на самом деле — из каких двух шагов она состоит?

Сначала происходит сборка проекта (компиляция всех `.cs` файлов),  
затем запускается уже готовая программа.

3. Зачем нужны папки `bin/` и `obj/` и почему их не нужно хранить в Git?

В папке `bin/` лежит готовая программа после компиляции.  
В папке `obj/` хранятся временные файлы, которые нужны только во время сборки.  
Эти папки создаются заново каждый раз при запуске `dotnet run`, поэтому их не хранят в Git (для этого используется `.gitignore`).

4. В чём разница между `git commit` и `git push`?

`git commit` сохраняет изменения только на твоём компьютере.  
`git push` отправляет эти сохранённые изменения на GitHub.

5. Чем отличаются конкатенация строк через `+` и интерполяция через `$"..."`? Какой способ предпочтительнее и почему?

Конкатенация через `+` просто склеивает строки, но код становится неудобным, если переменных много.  
Интерполяция через `$"..."` позволяет вставлять переменные прямо внутрь текста с помощью `{}`.  
Интерполяция удобнее и читается лучше, поэтому её предпочитают использовать.

6. Что произойдёт, если разделить `int` на `int`, если результат должен быть дробным? Как это исправить?

Результат будет целым числом — дробная часть просто отбросится.  
Чтобы получить точный дробный результат, нужно хотя бы одно из чисел сделать типа `double` (например, написать `(double)a / b`).
