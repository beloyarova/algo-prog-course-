# algo-prog-course-
ПР1. Ответы на контрольные вопросы

1. Чем компилируемый язык (C#) отличается от интерпретируемого (Python) с точки
зрения того, когда обнаруживаются ошибки?

У С# если есть ошибка в коде то компилятор откажется собирать программу то бишь она не запустится 

В Python об ошибке мы узнаем только дойдя во  время выполнения кода 

2. Что делает команда dotnet run на самом деле — из каких двух шагов она состоит?
1) Собирает проект
2) Запускает программу

3. Зачем нужны папки bin/ и obj/ и почему их не нужно хранить в Git?

bin/ содержит скомпилированную программу

obj/ хранит служебные промежуточные файлы сборки

Их не нужно хранить в Git потому что они пересоздаются командой dotnet run

4. В чём разница между git commit и git push?

git commit сохраняет изменения локально, в собственном репозитории

git push отправляет локальные изменения в удаленный репозиторий

5. Чем отличаются конкатенация строк через + и интерполяция через $"..."? Какой
способ предпочтительнее и почему?

Через конкатенацию мы склеиваем фрагменты текста 

А через интерполяцию мы подставляем значения переменных прям в текст

6. Что произойдёт, если разделить int на int, если результат должен быть дробным?
Как это исправить?

Если делить int на int то дробная часть просто отбрасывается

Чтобы получить точный ответ надо хотя бы одну переменную перевести в double

7. Чем const отличается от обычной переменной? Приведите свой пример, когда
стоит использовать const.

const это переменная значение которой которой передается один раз и не может изменятся 

А обычная переменная может менять значение много раз

const double pi = 3.14

8. Что такое top-level statements и чем они отличаются от классического class
Program{ static void Main() }?

top-level statements это способ писать код сразу, компилятор сам все дострои

А в классическом сам прописываешь класс и откуда начинается выполнятся программа
